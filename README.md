## 🛠️ Website (This Repo)

This is the official $BEASTSOL website built with **Next.js 16**, **Tailwind CSS v4**, **Framer Motion**, and **TypeScript**.

### Local Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

- ⚡ [Next.js 16](https://nextjs.org) + Turbopack
- 🎨 [Tailwind CSS v4](https://tailwindcss.com)
